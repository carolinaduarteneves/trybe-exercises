# Day 04 – Functions

### Overview  
On this day, I focused on understanding how functions work in JavaScript and how they can be used to organize code, reuse logic, and handle data more efficiently.  
The exercises involved working with functions, arrays, validation, and user input, reinforcing how functions help build dynamic and structured applications.

---

### What I learned  
- How to create and use arrow functions  
- How to pass parameters to functions  
- How to return values from functions  
- How to validate data using `typeof`  
- How to work with arrays using loops (`for`)  
- How to manipulate arrays with `.push()`  
- How to interact with HTML using `document.getElementById()`  
- How to convert values using `Number()`  
- How to use conditional logic to prevent errors  

---

### Practice  

#### 🔹 Exercise 07 – Add Products

- Used a loop to iterate through the new products  
- Validated that all values are strings before adding

---

#### 🔹 Exercise 08 – Filter Strings  
- Built a function to filter strings from an array  
- Checked if all elements are strings  
- Returned only strings with more than 4 characters  
- Practiced conditional logic and array manipulation  

---

#### 🔹 Exercise 09 – Student Average Calculator  
- Built a small web application using HTML, CSS, and JavaScript  
- Captured user input from input fields  
- Validated empty fields before calculation  
- Converted values from string to number  
- Calculated a weighted average  
- Displayed the result dynamically on the page  

---

### Key takeaway  
Functions are essential for organizing code and making it reusable.  
By combining functions with arrays, validation, and DOM manipulation, it is possible to create more structured and interactive applications.  
This day reinforced how important it is to validate data and break problems into smaller, reusable pieces.
