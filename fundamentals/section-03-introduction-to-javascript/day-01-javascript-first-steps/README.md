# Day 01 – JavaScript First Steps

## Overview
On this day, I focused on learning the basics of JavaScript and how it can be used to make web pages interactive.  
The goal was to understand how JavaScript interacts with HTML elements and how conditional logic can be used to create dynamic behavior based on user input.

## What I learned
- How to create and use JavaScript functions
- How to capture user input using `document.getElementById()`
- How to use conditional statements (`if`, `else if`)
- How to display results dynamically using `innerHTML`
- How to trigger actions using buttons and events
- How JavaScript allows a webpage to respond to user interaction

## Practice
- Built a **Grade Checker** web page
- Created a function that evaluates a student's grade
- Used conditional logic to display different messages depending on the grade
- Practiced connecting JavaScript with HTML inputs and buttons

## Key takeaway
JavaScript allows web pages to become interactive by responding to user input.  
By combining HTML elements with JavaScript logic, it is possible to build simple dynamic applications that provide feedback and improve the user experience.
