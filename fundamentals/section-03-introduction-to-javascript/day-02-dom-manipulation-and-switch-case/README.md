# Day 02 – DOM Manipulation and Switch Case

## Overview
On this day, I focused on learning how JavaScript interacts with the **Document Object Model (DOM)** to dynamically modify elements on a web page.  
The goal was to understand how JavaScript can control HTML elements, respond to user actions, and apply logic using conditional structures such as the **switch statement**.

## What I learned
- How to access HTML elements using `document.getElementById()`
- How to modify styles dynamically using JavaScript
- How to create interactive buttons that trigger JavaScript functions
- How to update content on the page using `innerHTML`
- How to apply conditional logic using the `switch` statement
- How JavaScript allows real-time interaction between the user and the webpage

## Practice

### Exercise 02 – Mood Text Changer
In this exercise, I built an interactive page that allows users to change the **color mood of the reading environment**.

Users can click buttons to activate different modes:

- **Calm Mode** – soft colors to create a relaxing reading experience  
- **Energy Mode** – brighter colors to create a more dynamic environment  
- **Focus Mode** – high contrast colors to improve concentration  

JavaScript was used to manipulate the DOM and dynamically change the background color of different sections of the page.

### Exercise 03 – Simple Math Calculator
In this exercise, I created a **basic calculator** that performs mathematical operations based on user input.

The user enters two numbers and a mathematical operator. The program then uses a **switch statement** to determine which calculation to perform.

Supported operations include:
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)

The result is displayed dynamically on the webpage.

## Key takeaway
DOM manipulation allows JavaScript to dynamically control and update elements on a webpage.  
By combining **user input, conditional logic, and DOM manipulation**, it is possible to create interactive web applications that respond to user actions.
