# Day 05 – Display Flex

## Overview
On this day, I focused on learning how to use **CSS Flexbox** to create responsive and well-aligned layouts.  
The goal was to understand how Flexbox can be used to organize elements on the page and combine it with JavaScript to create interactive behavior.

**Note:** The content of this project is written in Portuguese.

## What I learned
- How to use `display: flex` to organize elements  
- How to align items using `justify-content` and `align-items`  
- How to create responsive layouts with Flexbox  
- How to control spacing between elements using `gap`  
- How to combine CSS Flexbox with JavaScript interactions  
- How to manipulate element visibility using `style.display`  
- How to create dynamic user interactions with button events  

## Practice
During this lesson, I completed one exercise to practice Flexbox and DOM interaction.

### Exercise 07 – Interactive Gift List Page
In this exercise, I built an **interactive Easter gift list page**.

The page includes:
- A navigation bar with links to different sections  
- A structured layout using Flexbox  
- A themed design with images and categories (Skincare, Makeup, Hair, Others)  

The interface and text content are written in Portuguese.

I also created a simple interactive “game” where the user answers the question:

**“Does Carol deserve it?”**

- When the user clicks **“Yes”**:
  - A main button appears  
  - The “angry” image disappears  

- When the user clicks **“No”**:
  - The main button disappears  
  - An “angry” image appears  
  - An alert message is displayed  

This interaction was built using JavaScript event listeners and dynamic style changes.

## Key takeaway
Flexbox is a powerful tool for creating clean and responsive layouts.  
When combined with JavaScript, it allows developers to build interactive and engaging user experiences by controlling both layout and behavior.
