# Day 03 – Selectors and Positioning

## Overview
On this day, I focused on learning how to control the layout of a web page using CSS.  
The goal was to understand how to select elements precisely and position them on the page to create well-organized and visually consistent layouts.

## What I learned
- How the CSS Box Model works and how elements relate to each other visually
- How to position elements on the page using different CSS positioning methods
- How to combine and group CSS selectors to create clear and specific styling rules
- How to use pseudo-class selectors to apply conditional styling
- How to integrate images into page layout and control their positioning
- How to style links and create interactive states using pseudo-classes like :hover and :active
- How to organize content into visually distinct sections using CSS classes and IDs

## Practice
- Practiced styling elements using different types of CSS selectors
- Applied positioning techniques to control layout and element placement
- Used pseudo-classes to add interactive and conditional styles
- Built a complete webpage about SDG 13 — Climate Action
- Styled headings, paragraphs, lists, and images to create a clear visual hierarchy
- Positioned images alongside text using CSS positioning techniques
- Applied selectors using classes and IDs to control specific elements
- Integrated external links to official climate data sources

## Key takeaway
Understanding selectors and positioning in CSS is essential for building structured layouts and organizing content effectively. This exercise also demonstrated how CSS selectors and positioning are fundamental for creating real-world webpages with organized content, images, and interactive elements.
