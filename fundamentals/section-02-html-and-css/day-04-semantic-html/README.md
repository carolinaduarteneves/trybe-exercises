# Day 04 – Semantic HTML

## Overview
On this day, I focused on learning how to structure web pages using **semantic HTML elements**.  
The goal was to understand how semantic tags improve the organization of a webpage, making the code clearer, more accessible, and easier to maintain.

## What I learned
- The purpose of semantic HTML elements  
- How to structure a webpage using tags like `header`, `nav`, `main`, `section`, `article`, `aside`, and `footer`  
- How semantic elements improve accessibility and SEO  
- The importance of organizing content into meaningful sections  
- How semantic HTML helps developers understand the structure of a webpage  
- How to combine semantic HTML with images and descriptive `alt` attributes  

## Practice
During this lesson, I completed two exercises to practice semantic page structure.

### Exercise 05 – Semantic Page Layout
In this exercise, I created a basic webpage layout using semantic HTML elements such as:

- `header`
- `nav`
- `main`
- `article`
- `section`
- `aside`
- `footer`

The goal was to understand how these elements help define the structure and purpose of each part of a webpage.

### Exercise 06 – Sweet Essence Bakery Page
For this exercise, I built a **bakery landing page called Sweet Essence**.

The page includes multiple semantic sections, such as:

- About Us  
- Our Story  
- Custom Cakes  

Images, text content, and structured sections were used to simulate a **real website layout for a bakery**.

## Key takeaway
Semantic HTML allows developers to create cleaner and more meaningful webpage structures.  
Using semantic elements improves readability, accessibility, and maintainability, making it easier for both developers and browsers to understand the layout of a page.
