# Day 02 – Working with Elements

## Overview
On this day, I focused on learning how to manipulate the DOM using JavaScript.  
The goal was to understand how to dynamically create, insert, and organize HTML elements directly through JavaScript.

## What I learned
- How to create elements using `document.createElement()`  
- How to add text content using `innerText`  
- How to select elements using `querySelector()`  
- How to append elements to the DOM using `appendChild()`  
- How to assign classes using `.className`  
- How to create structured layouts dynamically with JavaScript  
- How to build lists using loops and arrays  
- How to combine JavaScript with CSS for styling  

## Practice

### Exercise 02 – Travel Agency Page
In this exercise, I built a complete webpage structure dynamically using JavaScript.

The page was created entirely through DOM manipulation and includes:

- A main title (`h1`)  
- A main container (`main`)  
- Three sections:
  - Center content  
  - Left content  
  - Right content  

Inside the sections, I added:

- A paragraph describing a travel agency  
- An image displayed in the left section  
- An unordered list generated from an array of numbers (from one to ten)  

The list was created dynamically using a loop, where each item was inserted as an `<li>` element.

This exercise helped simulate how real applications generate content dynamically instead of relying only on static HTML.

## Key takeaway
JavaScript can be used to fully control the structure of a webpage.  
By dynamically creating and organizing elements, developers can build flexible and interactive interfaces without manually writing all HTML content.
