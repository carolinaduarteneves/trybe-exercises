# Day 01 – DOM Manipulation

## Overview
On this day, I focused on learning how to manipulate elements on a webpage using **JavaScript and the DOM (Document Object Model)**.

The goal was to understand how JavaScript can interact with HTML elements, respond to user actions, and dynamically update the page content.

Through practical exercises, I explored how to select elements, handle events, and update the interface in real time.

## What I learned
- How to select HTML elements using `querySelector` and `querySelectorAll`
- How to modify text content using `.textContent`
- How to add event listeners using `addEventListener`
- How to handle click events
- How to control game logic using JavaScript functions
- How to restart application states dynamically
- How to manipulate the DOM to update user interfaces

## Practice

### Exercise 14 – Tic Tac Toe Game
In this exercise, I built a **Tic Tac Toe game** using JavaScript and DOM manipulation.

The game allows two players to take turns placing **X** and **O** on the board. JavaScript controls the game logic and checks if a player has won.

The exercise included:

- Creating a 3x3 game board
- Selecting all board cells using `querySelectorAll`
- Handling player clicks using `addEventListener`
- Alternating turns between **X** and **O**
- Detecting winning combinations
- Displaying a message when a player wins
- Resetting the game using a restart button

The game logic checks predefined winning combinations to determine if a player has completed a row, column, or diagonal.

This exercise helped me understand how JavaScript can control game logic while dynamically updating the DOM.

### Exercise 15 – To-Do List
In this exercise, I created a **To-Do List application** using JavaScript.

The goal was to practice adding and managing tasks dynamically using DOM manipulation.

The exercise included:

- Creating an input field to add tasks
- Adding tasks to a list dynamically
- Updating the page without refreshing
- Using event listeners to respond to user actions
- Practicing DOM element creation and manipulation

This exercise demonstrated how JavaScript can be used to build simple interactive applications.

## Key takeaway
DOM manipulation allows developers to create dynamic and interactive web pages.

By combining **event handling, element selection, and JavaScript logic**, it becomes possible to build applications that respond to user actions in real time.

These exercises helped reinforce how JavaScript can control the behavior of elements on a webpage and create interactive user experiences.
